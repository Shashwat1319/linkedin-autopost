Skills my job interviews never test, but work uses daily:

→ Reading a5,000-line file and finding your way
→ Writing the message you'd want as an error
→ Saying "I don't know — I'll find out" without crumbling
→ Estimating honestly: "2 days, not 2 hours"
→ Asking what happens when the input is EMPTY, not the demo case

None of these are on a syllabus.
All of them show up in week one of any job.

Technical skills get you screened.
These get you trusted.

Which of these do YOU feel least confident in?
