My path into open source (no明星 repos needed):

1. Start as a USER — file a real bug with repro steps
2. Fix docs — typos, missing examples, wrong imports (maintainers LOVE this)
3. Pick "good first issue" — small, scoped, testable
4. Read CONTRIBUTING.md like it's the law — because it is
5. Open the PR with: what, why, how tested

First PRs get merged for being CLEAR, not clever.

Open source isn't a portfolio stunt. It's:
→ Code review from strangers who don't care about your feelings
→ Proof you can work in someone else's system
→ Connections that don't come from applications
