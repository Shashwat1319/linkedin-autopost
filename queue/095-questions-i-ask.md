Questions that made me look senior (as a junior):

Before starting ANY task:
→ "What does DONE look like?" (definition of success)
→ "Who else touches this? Will it break their flow?"
→ "What's the failure case nobody's mentioned?"
→ "Should I match existing patterns or can I improve them?"

In code review of MY code:
→ "What did you consider and reject?" (shows thinking)
→ "Where will this break at 10x load?"

After a bug:
→ "How do we know this class of bug is gone?" (the test)

Seniors aren't people with more answers.
They're people who ask the question that prevents the next3 bugs.

Which question do YOU wish you'd started asking earlier?
