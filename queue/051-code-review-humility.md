My first code review: someone rewrote half my PR.

My ego: destroyed.
The code: better.

What I learned to separate:
→ Feedback on CODE ≠ feedback on ME
→ "This doesn't handle empty arrays" is not "you're stupid"
→ The reviewer's time is a gift — they read MY code instead of shipping theirs

Now I review the same way:
→ What would break in prod? (say it first)
→ One thing they did WELL — so the correction lands
→ Questions before directives: "What if the input is null here?"

The best juniors aren't right. They're fast at becoming right.

How do YOU handle feedback on a PR you're proud of?
