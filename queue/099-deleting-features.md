The feature I deleted last month — best decision of the week:

It was a "customization panel."12 settings.
Usage data: 4% of users opened it. 0.4% changed anything.

Cost:3 screens of UI,200 lines, bug reports every other week, docs nobody read.

Deleted. Nobody noticed. Support tickets dropped.

Every feature taxes your codebase:
→ More states to test
→ More combinations to break
→ More explanations for every new developer

The skill isn't adding. It's subtracting while the user still smiles.

My new rule: any feature needs an exit criteria — "if usage < X% in 30 days, we remove it."
