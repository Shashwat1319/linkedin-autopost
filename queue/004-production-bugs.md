What I learned fixing 20+ production bugs in 6 months as a MERN developer:

→ Most "bugs" are state bugs — stale cache, race condition, or an unhandled promise
→ Logs at the right place beat 30 console.log scattered everywhere
→ Write the fix first, then write the test that would have caught it
→ The scariest bugs are the ones only reproducible in production — so make your dev env mirror prod

Stability is a feature you build on purpose.
