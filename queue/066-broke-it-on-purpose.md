How I learn a system: I break it on purpose.

When I get access to any codebase (or my own project):
→ Delete a feature branch — what breaks?
→ Point the API at localhost — which error appears?
→ Log in as the WRONG role — what leaks?
→ Fill the form with 10,000 characters — does it hold?
→ Turn off the backend entirely — what does the frontend show?

You don't understand a system by reading it.
You understand it by watching it fail — safely.

This is also how I write tests: every bug I break becomes a test that can never come back.
