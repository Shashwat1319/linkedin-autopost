Try this uncomfortable exercise:

Open code you wrote 6 months ago.
Read it like it's someone else's PR.

You'll find:
→ A function doing 4 things, named like it does one
→ A "temp" variable that's now load-bearing
→ Comments that LIE
→ That "quick fix" you forgot about

I do this quarterly now. Not to feel bad — to see progress AND patterns.

The bugs you always write are your signature. Mine was: skipping null checks on API responses. Now I see them coming.

Your old code isn't embarrassing. It's evidence of motion.

When did you last read your own year-old code?
