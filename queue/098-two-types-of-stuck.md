Two kinds of stuck (and they need opposite medicine):

Type 1: "I don't know HOW."
→ Search the specific error message, not the whole concept
→ Read docs for the ONE function that's failing
→ 30 minutes max, then ask with context (repro + what you tried)

Type 2: "I know how, I just can't START."
→ Write the worst possible version — names and all
→ Do the5-minute piece that's obvious
→ Close the tab if needed — the idea doesn't decay overnight

Mixing them up wastes days:
→ Googling when you needed to just START
→ Pushing through when you needed ONE question

Which type are you usually? I'm Type 2, and it took me years to admit it.
