My zero-cost deployment map (what I actually use):

Frontend: Netlify / Vercel — free tiers, auto-deploy on git push
API: free container/render tiers — enough for portfolios and side projects
Database: MongoDB Atlas free cluster — real cluster, real backups
Auth: self-hosted JWT — no per-user pricing
CI/CD: GitHub Actions — 2000 free minutes/month, plenty
Monitoring: uptime checks + basic error logging

Total cost of my entire portfolio + side projects: ₹0/month.
