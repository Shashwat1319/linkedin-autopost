UI states most devs build (2 of 7):

1. Content ✓
2. Loading spinner ✓

What users actually hit:
3. Empty — "No orders yet" + a CTA, not a blank page
4. Error — with a retry button, not a dead end
5. Partial — some data loaded, rest pending
6. Offline — "You're offline, here's what we cached"
7. Success after action — toast, checkmark, SOMETHING

A page that only handles happy paths is a demo, not a product.

My rule: before shipping any list or dashboard, I write down ALL states — including the sad ones.

Which state do you always forget to build? (Mine: empty.)
