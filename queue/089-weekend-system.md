My weekend structure (loose, not a prison):

Saturday morning: DSA — the hard stuff when brain is fresh
Saturday afternoon: project work — the deep, satisfying stretch
Saturday evening: OFF. guilt-free.

Sunday:1 hour admin (applications, emails, notes) + 1 hour learning ONE thing
Sunday night: plan Monday's single priority (write it down)

What I stopped doing:
→ "Productive" 14-hour days that burned5 days of energy
→ Planning every hour (life happens)
→ Working through weekends "to catch up" — never caught up

Rest is part of the system. Burned-out developers ship nothing.
