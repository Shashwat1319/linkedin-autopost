A boundary that saved a client relationship:

Client at9 PM: "Small change. Should take5 minutes, right?"

My old self: drop everything. Resentment builds. Quality drops.
My reply: "I'll pick it up first thing tomorrow morning — will have it by 11."

Result: they respected the time MORE. Nothing broke overnight. I slept.

Boundaries that work:
→ Response windows ("I reply9 AM–7 PM")
→ Estimates before work ("that's half a day, not 5 minutes")
→ One channel for requests (not WhatsApp + email + calls)
→ "Yes, and..." — yes with a cost attached, so scope stays visible

Undervalued workers don't get boundaries. RESPECTED workers do.
